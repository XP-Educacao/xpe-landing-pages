Como funciona o Exame Especial?

É uma oportunidade de recuperação para estudantes que não alcançaram a aprovação no bootcamp, mas atenderam aos critérios de elegibilidade.

Quem pode realizar?

Alunos com 200 a 349 pontos (40% a 69%) no bootcamp, frequência mínima cumprida e prova presencial regular realizada.

O que preciso para ser aprovado?

Alcançar 350 pontos ou mais no Exame Especial. A nota final registrada será de 350 pontos, mesmo que a nota do exame seja maior.

E se eu não alcançar a nota?

Será mantida a maior nota entre a avaliação regular e o Exame Especial, e o aluno permanecerá reprovado.

Tenho mais de um bootcamp reprovado

É necessário adquirir um exame para cada bootcamp. As avaliações acontecem na mesma data, sendo uma prova para cada bootcamp.

Perguntas frequentes

Posso realizar o exame em outra data?

A data oficial é fixa: 16/12/2026. Se você não puder comparecer, procure o suporte para apresentar sua situação. Pedidos excepcionais serão analisados caso a caso, sem garantia de atendimento.

O Exame Especial é on-line ou presencial?

É exclusivamente presencial. Você deve indicar o polo no formulário e comparecer na data informada.

Preciso pagar novamente para escolher o polo?

Não. Esta página é apresentada após a compra do Exame Especial e a escolha do polo não representa uma nova compra.

Como funciona se eu tiver mais de um bootcamp reprovado?

É necessário ter adquirido um Exame Especial para cada bootcamp. Todas as avaliações ocorrerão em 16/12/2026, com uma prova específica para cada bootcamp.

Qual nota preciso tirar para passar?

Você precisa obter pelo menos 350 pontos no Exame Especial. Se aprovado, sua nota final no bootcamp será registrada como 350 pontos.

Como consulto o endereço do polo?

Abra “Consultar os polos disponíveis e endereços”, nesta mesma página, para conferir os endereços antes de preencher o formulário. O horário da prova será informado pelos canais oficiais da instituição.
